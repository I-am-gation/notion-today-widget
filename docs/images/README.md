## 这些图怎么来的

所有图都用**演示数据**拍摄，不含真实日程。做法是在 Notion 里临时建了一个测试库，塞入五条假任务（整理本周学习笔记、回复项目邮件、写项目周报、跑步 30 分钟、读《代码整洁之道》第 3 章），让挂件的一个隔离实例指向它。拍完已把该库归档删除。

- **不碰真实数据**：整个过程没有读写「周计划」库里的任何一条记录。
- **不碰本机配置**：隔离实例跑在临时目录里，用的是那份目录下的配置副本，项目里的 `config.json` 未被修改。
- **背景不透出**：拍摄时把 `acrylic_color` 的 alpha 从 `E6`（90%）改成 `FF`（不透明），这样桌面布局和壁纸不会被截进去。

另外：

- `sync.gif` 是**真实点击、真实同步**。点击位置由脚本计算后发送鼠标事件，同步是真的写到了那个测试库。
- `tray-menu.png` 与其他三张不同：**它不是屏幕截图，而是用 Qt 渲染的菜单控件**。因为本机托盘图标默认收在隐藏溢出区，反复试探托盘区域会不断把桌面私有内容截进来。这张图的菜单项文字、顺序、分隔线、勾选状态都逐行取自 `notion_widget.py` 的 `main()`，是同一个 `QMenu` 类的真实渲染结果，只是没有桌面背景。
- 拍摄脚本用完即删，临时目录里含令牌的配置副本也已清除。

## 要重拍的话

- `widget.png` / `sync.gif`：需要先有一个装有假任务的数据库，再按上面的隔离实例方式拍。
- `zorder-compare.png`：遮挡窗口用一个纯色窗口即可（脚本里那个是 564×384 的深灰面板）。
- `tray-menu.png`：直接渲染菜单即可，不必去动托盘。
- 首图建议保持不透明底色；半透明会把壁纸和桌面布局带进画面。
