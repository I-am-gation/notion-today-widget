## 为什么需要这三张

- `sync.gif` 证明「勾选真的会同步回 Notion」——静态图证明不了这件事，只有动图能。
- `zorder-compare.png` 说明标题栏那个「顶 / 桌」按钮切换的到底是什么——这个差异光读代码看不出来。
- `tray-menu.png` 展示程序除主窗口外的入口，尤其是「开机自启」这个开关。

## 录制注意

- **必须用测试数据**。截图/录屏前把 Notion 里的任务换一批假的，或事后打码。
- **`config.json` 绝不能入镜**。它含明文令牌；截图前关掉编辑器里打开该文件的窗口。
- 壁纸建议用中性图片；或者把挂件拖到一块纯色窗口上方再截，避免带出桌面布局。
- 首图建议用**不透明**底色截（`config.json` 里 `acrylic_color` 的 alpha 从 `E6` 改到 `FF`），这样背景不会透出来。
- GIF 控制在 2MB 以内，GitHub 上加载才顺畅。

## `widget.png` 是怎么来的

用一个隔离实例拍的（不依赖你正在用的那份配置）：

1. 临时目录里放一份 `notion_widget.py` + 一份把 `acrylic_color` 改成 `0xFF1A1A20`（不透明）的配置——避免背景透出桌面布局；
2. 启动后等任务加载完，截取挂件所在矩形；
3. 对任务文字与类型标签区域做像素化，保留勾选框、标题栏、底部状态栏；
4. 裁成 364×292 并加 8px 圆角透明遮罩（去掉圆角外的桌面像素）。

要重拍就在仓库根目录跑类似流程；注意重拍版本同样要打码。
